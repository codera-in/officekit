# Bundled font notices

`NotoSansTamil-Regular.ttf` is a static instance of Noto Sans Tamil, generated
from `NotoSansTamil-VF.ttf` at its default axes for ReportLab compatibility.
Both are distributed under the SIL Open Font License 1.1. The full license and
copyright notice are in `OFL-NotoSansTamil.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/notosanstamil

The PDF result exporter embeds the static font so Tamil output does not depend on
an optional system font. Its font coverage is checked before rendering.

`NotoSans-Regular.ttf` is the hinted static Noto Sans Regular (Latin, Greek and
Cyrillic), SHA-256 `478c558ea716033cd60c03438f628dfa75694dcf6b5f6d505a2f05fd2b4f3823`.
It is distributed under the SIL Open Font License 1.1; the full license is in
`OFL-NotoSans.txt`. PDF watermarks, page numbers and image contact-sheet labels
embed it so Latin text does not depend on a system font.

Source: https://github.com/notofonts/notofonts.github.io/tree/main/fonts/NotoSans/hinted/ttf
