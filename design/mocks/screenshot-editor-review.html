Screenshot editor

A before-and-proposed flow for your request to paste a screenshot, crop it, blur private details or cover them with an opaque mask, then save a clean copy. Images stay local; clipboard access happens only after the user presses Paste.

Local processing · no upload · selected image and undo history are temporary.

Proposed safeguards: clipboard is never read on launch; only image data is accepted after an explicit click. Limit input to 64 MiB / 40 megapixels, cap edits to 20 undo steps, export metadata-free PNG/JPEG, and clear the temporary image on Clear or when the screen closes.
