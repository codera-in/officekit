This map records focused feature coverage; the repository-wide gates and installed acceptance checklist remain in `docs/TESTING.md`.

Speech model first-use lifecycle: `tests/speech-model-native.test.mjs`, `tests/dictation-ui.test.mjs`, Rust lifecycle and registration tests, `tests::cached_speech_first_use_memory_profile`, and vendored FluidAudio cached-bridge tests. Cover zero-weight startup registration, first-decode loading and reuse across entry points, missing/corrupt cache rejection without mutation or download, simultaneous resolution, and surfaced failure cleanup. The memory profile uses cached Whisper with synthetic audio and excludes the desktop UI/backend; Parakeet/Qwen3 inference requires weights not present in the test environment. See `docs/verification/speech-model-memory.md`, P-272–P-276 and CR-335.

Speech Coach clarity: `tests/fixtures/speech-coach/clarity.json` preserves the entire real brainstorm. Rust tests cover sentence extraction, original transcript marking, corrected Copy, bounded/grounded rewrites, unchanged numbers, malformed outputs and grammar fallback. `tests/speech-coach-clarity.test.mjs` guards production focus-3 wiring (red when the call is changed to focus 1). `ui-tests/coach-workspace.spec.mjs` verifies the transcript remains spoken text with no inline rewrite while Improvements provides the sole actionable correction at desktop and compact widths. `npm run test:coach-model` checks four actual local-model rewrites and two already-clear contrasts; unavailable models explicitly skip. Installed microphone acceptance is separate. See `docs/verification/speech-coach-clarity.md`, P-266, P-277 and CR-331.
