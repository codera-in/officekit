## Decision and scope

Ship a verified subset first and add the remaining tools in tested updates. The 123-capability roadmap remains the long-term goal; reaching a marketing count must not delay the first useful release or justify shipping broken tools.

Confirmed channel: **private beta first, then paid release**. The current source profile exposes 50 tools (including the Speech Coach catalogue card): the five Ergonomics reminder tools (break, eyes, water, posture, meeting countdown; owner decision 2026-10-23, every build has them), 17 calculator/developer candidates below, seven selected-file workspace tools, the supported bank-statement exporter, eleven PDF actions (page deletion, page reordering, selectable text extraction, lossless compression, page-to-image export, metadata removal, selectable-table export, merge, grouped split, known-password unlock, and password protection), three image tools (conversion, resize, and metadata cleanup), separate local Voice Transcription and Meeting Notes tools, Find & Mask Personal Information, and two redacted System tools. This enables real workflow testing but does not certify installed-Mac behavior.

The extra IDs enabled for this test build are `voice_transcription`, `meeting_notes`, `system_info`, and `system_resources`; downloaded speech models remain optional and separate from the installer.

Current source contains **59 catalogue entries and 58 coded families**. None has a complete recorded installed-Mac release sign-off. API wiring, passing unit tests and a DMG that builds are separate evidence, not synonyms for production-ready. Every PDF action except page deletion, page reordering, selectable text extraction, lossless compression, page-to-image export, metadata removal, selectable-table export, merge, grouped split, known-password unlock and password protection remains outside the restricted 44-tool private-beta profile. Local speech models are downloaded only when selected; they are not bundled into the installer. The five ergonomics entries are in every build, including private beta, by owner decision (2026-10-23); installed-Mac acceptance of each is still required.

Prioritize **42 catalogue tools** for the private-beta test build. Seven use isolated copies in a process-owned local workspace; originals stay unchanged. The image converter handles only formats listed in its UI; JPEG/BMP flatten transparency onto white, and animation or multiple pages are preserved only by compatible targets. Batch image resize preserves originals, bounds transfer and decoded pixel work, reports recoverable failures, and emits collision-safe output names. Image metadata cleanup returns a copy and preserves supported animated GIF frames/timing; no tool can promise removal of every application-specific or embedded private field in every proprietary format. The bank-statement exporter is limited to supported layouts and requires row review; it does not convert arbitrary PDF tables. Selectable-table PDF export is limited to detected text tables; scanned pages, OCR, unruled layouts, and broad third-party PDF fidelity are not promised. Selectable text extraction has 50-page, 64 MiB input and 8 MiB output bounds, preserves requested page order, and reports pages without text; scanned-only documents do not receive OCR in this tool, and complex reading order remains an explicit limitation. Page deletion removes the selected page widgets from AcroForm fields while retaining widgets on surviving pages; it is page removal, not secure redaction. Page reordering keeps page geometry, form fields, internal links and outlines attached to their content in tested documents. The bank statement supplied for acceptance exports four reconciled rows, while synthetic table fixtures preserve identifiers and neutralize spreadsheet formulas. The bundled offline OCR passes raster-only, rotated-raster, weak-vector and packaged-sidecar fixtures, but broader statement accuracy remains unproven. PDF compression is lossless stream recompression with pixel-identical rendered output on tested documents; it may make some files larger. PDF page export renders selected document pages as an ordered JPEG/PNG ZIP with bounded resolution. Metadata removal strips standard document information and root XMP metadata, but embedded identifiers may remain. PDF unlocking only accepts a password already known to the user; protection encrypts a new copy and asks users to retain their chosen password. Merge and grouped split retain the original inputs and produce new outputs. Keep image similarity and other unverified workflows outside the beta. The remaining **4 candidates** need deeper acceptance; **5 catalogue entries are held back** for known failures or substantial gaps. Beta inclusion is not a production sign-off.

## Promotion and release gates

1. **Engine:** independent expected results; invalid/boundary/malformed input, privacy and bounded work. No unresolved defect in the advertised scope.
2. **UI:** exact gallery/search destination; real local API interaction, keyboard path, actionable errors, clear/copy/download and required save/reopen flows. Verify original snapshot data survives edits and reload.
3. **Package:** pinned build; packaged API fixtures; installed application starts cleanly without a development server. DMG smoke alone verifies the packaged backend, not interactive native behavior.
4. **Mac acceptance:** install and launch on the supported Mac matrix; actual file pickers/permissions/clipboard where applicable. Record build identifier, test case, observed result and verifier. Current native automation returns `Sky Computer Use native pipe startup failed`, so this evidence is still missing.
5. **Distribution:** define supported Mac architecture/OS and channels; sign/notarize and verify Gatekeeper on a clean machine. A paid public release additionally needs production license/device activation, customer support and tested updates. FakeCloud integration does not establish a deployed commercial service.

Only promoted IDs should appear in the restricted build's catalogue, search, quick access and direct navigation. Enforce the same scope at the local command/API boundary; a hidden tile is not a disabled feature. Keep existing private development builds separate. Beta labeling is explicit; do not sell an unverified build as production-ready.

An update adds a tool only after its gates pass. Release notes list actual added capability and limits; verify saved-record compatibility and provide a rollback path. Do not promise an upgrade date or inflate counts with format combinations.
