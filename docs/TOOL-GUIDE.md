## Depth scale and table legend

| Depth | Meaning |
| --- | --- |
| D1 — Primitive/prototype | Narrow implementation or provider-dependent wrapper; important behavior missing or correctness risks unresolved |
| D2 — Basic functional engine | Useful normal-input behavior with some outputs/options, but integration/safety/edge cases incomplete |
| D3 — Product-complete tool | Exact UI route, validated boundaries, safe outputs, errors/jobs where relevant, exports/history/privacy and meaningful tests |
| D4 — Release-verified | D3 plus clean-machine packaging, cross-platform fixtures/accessibility and actual release evidence |

No family is assigned D3/D4 on this source-only review. D1/D2 indicate observed scope, not a test pass or commercial security approval. API/UI are independent of depth. ## Unruled bank-statement PDF extraction (2026-10-07)

When the PDF table detector returns no table or a structurally weaker table, the parser now groups positioned PDF words into header-anchored columns, joins wrapped description-only lines within a bounded 24-point leading, and skips undated summary/count rows and detached footer text. Generated vector-PDF regressions cover 12- and 20-point leading, reject a detached note beyond the bound, and cover merged extraction recovery while preserving clean ruled extraction behavior; the rebuilt macOS arm64 sidecar passes the authenticated unruled-PDF API smoke. The supplied statement copy in the project input folder was also tested through the local API and desktop WebKit flow; it produced four separate transaction rows and a four-row CSV. The screenshot-shaped merged-date case remains separately covered by its synthetic regression.


## PDF password protection round trip (2026-10-07)

The multipart API regression now protects a two-page PDF, independently reopens it with the chosen password, unlocks the returned attachment, and reopens it without a password. ## Native dictation model runtime acceptance (2026-10-08)

On Apple silicon, `npm run test:parakeet-runtime` passed using the cached Parakeet v3 model: generated speech was transcribed from a WAV file and twice from capture-shaped sample buffers. `npm run test:qwen3-runtime` passed using the cached Qwen3-ASR model on generated long-form speech that exercises overlapping chunk boundaries. Both acceptance runners check for regular, complete model-cache artifacts and do not download models unless an explicit allow-download environment flag is set. These checks establish CoreML inference for generated English fixtures; they do not verify microphone permissions, push-to-talk in the installed app, multilingual accuracy, or dictation quality across real speakers.
