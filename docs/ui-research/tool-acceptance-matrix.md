## Result capability verification

For each computed result, record the actual full-data adapter and supported formats. Text/number results need complete Copy and Download; table exports preserve all rows and CSV formula safety; binary outputs need relevant file download and an explicitly labelled summary copy or rendered image copy where appropriate. Actions with no computed result require honest success/cancellation instead of artificial exports.

For every row verify failure clearing, pending status, clipboard denial, save cancellation, large-copy limits and stale-input separation. A preview-only or truncated copy fails the complete-output check. Use the repository officekit-ux-verification skill for design and installed evidence modes.
