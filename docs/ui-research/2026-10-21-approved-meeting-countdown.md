# Approved animated meeting companion

Version: 1.0.0 · Approved 2026-10-21.

Owner request: “Use our mascot and build read the user calendars on the local system and show a timer when there is a meeting is coming up in next 30 minutes.” Refinement: “I WANT full animation”. The revised animated mock was inspected in a new Superset Browser tab and the owner replied **“approved”**.

Approved direction: macOS-first local calendar access; selected calendars; 30-minute countdown with the existing original character and corner placement; hide one meeting occurrence; permission/denied states; character poses checking/tapping a watch, pointing and waving at start, with reduced-motion fallback. Meetings share existing quiet hours and pause. No account login, event writes, uploaded event contents or persisted event cache.

Reviewed mock used sample data. Generated poses establish the approved animation direction, not a claim of smooth rigged animation. Source sheet: `design/assets/meeting-companion-animation-v2.png`; bundled copy: `assets/ergonomics/meeting.png`. Initial sheet retained a third arm from the stretching reference; v2 removes it. Temporary mocks and preview server are removed after approval per repository policy. Existing development-profile gate is retained.
